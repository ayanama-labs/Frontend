# Pseudo-classes & Pseudo-elements

## 1. Pseudo-classes

Pseudo-classes select elements based on their **state or condition**.

```css
button:hover {
}
input:focus {
}
```

Advanced ones:

### `:not()`

Selects elements that **do not match** the selector.

```css
p:not(.special) {
  color: gray;
}
```

Selects all `<p>` except those with `.special`.

```css
li:not(:last-child) {
  margin-bottom: 10px;
}
```

---

### `:is()`

Groups multiple selectors into one.

```css
:is(h1, h2, h3) {
  color: blue;
}
```

Equivalent to:

```css
h1,
h2,
h3 {
  color: blue;
}
```

Useful for simplifying complex selectors:

```css
.card :is(h1, h2, p) {
  margin: 0;
}
```

---

### `:where()`

Works like `:is()` but has **zero specificity**.

```css
:where(h1, h2, h3) {
  margin: 0;
}
```

### `:is()` vs `:where()`

```text
:is()   → specificity = specificity of its most specific argument
:where() → specificity = 0
```

Use `:where()` when you want styles that are **easy to override**.

---

# 2. Pseudo-elements

Pseudo-elements style or create a **specific part of an element**.

They use `::`:

```css
p::first-line {
}
p::first-letter {
}
```

Common generated-content pseudo-elements:

```css
::before
::after
```

---

## `::before`

Creates generated content **before the element's actual content**.

```css
h2::before {
  content: "★ ";
}
```

Result:

```text
★ My Heading
```

---

## `::after`

Creates generated content **after the element's actual content**.

```css
h2::after {
  content: " →";
}
```

Result:

```text
My Heading →
```

---

# 3. `content` Property

`content` specifies the content generated by pseudo-elements.

```css
p::before {
  content: "Note: ";
}
```

Output:

```text
Note: This is important.
```

`content` is primarily used with `::before` and `::after`.

### Empty content

Often used when the pseudo-element is purely decorative:

```css
.box::before {
  content: "";
}
```

---

# 4. Generated Content Techniques

### Add symbols

```css
li::before {
  content: "✓ ";
}
```

### Add text

```css
.external::after {
  content: " ↗";
}
```

### Add attribute values

```html
<a href="https://example.com">Example</a>
```

```css
a::after {
  content: " (" attr(href) ")";
}
```

Can generate content using the element's attribute.

---

### Counters

CSS counters can generate numbering.

```css
body {
  counter-reset: section;
}

h2::before {
  counter-increment: section;
  content: counter(section) ". ";
}
```

Result:

```text
1. Introduction
2. Installation
3. Usage
```

# Quick Revision

```text
Pseudo-class
→ selects an element based on state/condition

:not()
→ excludes matching elements

:is()
→ groups selectors
→ normal specificity

:where()
→ groups selectors
→ zero specificity

Pseudo-element
→ targets/creates part of an element

::before
→ generated content before actual content

::after
→ generated content after actual content

content
→ defines generated content
→ mainly used with ::before / ::after
```

### Golden distinction

```text
:  → pseudo-class
     button:hover

:: → pseudo-element
     p::before
```

**Pseudo-class = "which condition?"**
**Pseudo-element = "which part?"**
